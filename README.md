# Dr.1 – معالجة وتصنيف صور القطط والكلاب

## وصف المشروع
تم تنفيذ درس معالجة الصور واستخراج السمات من صور القطط والكلاب، ثم تدريب ومقارنة عدة خوارزميات للتصنيف.

## البيانات
- 28 صورة تدريبية: 14 قطط و14 كلاب.
- صور اختبار إضافية موجودة داخل مجلد `test`.

## خطوات التنفيذ
1. قراءة صور القطط والكلاب.
2. تغيير حجم الصور إلى 128×128.
3. استخراج متوسط وانحراف ألوان BGR.
4. تحويل الصور إلى HSV واستخراج Histogram لوني.
5. حفظ السمات في `extracted_features.xlsx`.
6. تدريب ومقارنة Random Forest وSVM وKNN وDecision Tree.
7. حفظ نموذج Random Forest في `cat_dog_model.pkl`.
